# SaaS Ecosystem: System Instructions (Ibrahim Architecture)

## 1. Core Philosophy
- **Leanness**: No `node_modules`, `.next`, or build caches in the repo.
- **Source + Context**: Every app must have its source code accompanied by a `CONTEXT.md`.
- **Portability**: The system must be re-buildable from scratch on any device in <30 minutes.

## 2. Sync Protocol
- When uploading: Only push source code, configuration (JSON/YAML/MD), and metadata.
- When downloading: Antigravity must first read `ARCHITECT.md` and `HANDOVER.md` to restore the mission state.

## 3. Mission Priorities
- **Priority 1**: Novu Revenue Platform (Active Development).
- **Priority 2**: Sovereign Growth Engine (Active - Lead Gen for Novu).
- **Priority 3**: Sentrix / Cliniq OS / Healthcare OS (Supporting Infrastructure).
- **Legacy**: Axon is dead. Reference only.
